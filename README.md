# Eternal Legacy · Launcher

Launcher oficial de **Eternal Legacy** (World of Warcraft: Wrath of the Lich King 3.3.5a).

## Descargar

Baja el instalador de la [última release](https://github.com/neeme22/azeroth-reborn-launcher/releases/latest)
(`EternalLegacy-Setup-<versión>.exe`) y ejecútalo.

## Qué hace

- Instala el juego, lo mantiene actualizado y lo repara si falta o se estropea algún fichero.
- Muestra el estado del reino y las novedades del servidor.
- Abre el juego ya configurado para conectar al reino.

Las versiones del juego se publican en [game-client-dist](https://github.com/neeme22/game-client-dist/releases).

Las releases 1.0.0 y 1.0.2 de este repositorio son del launcher antiguo (Azeroth Reborn) y se conservan como archivo.
